# VisionCommand AI v0.5.2

## Release Theme

VisionCommand AI v0.5.2 is a documentation visualization patch release.

This release adds Mermaid architecture diagrams to the architecture overview documentation. It does not change frontend or backend runtime behavior.

The goal is to make the system architecture easier to understand visually while keeping the diagrams directly renderable inside GitHub Markdown.

---

## Why This Release Matters

v0.5.1 completed the documentation audit and reorganized the repository documentation into a more professional structure.

v0.5.2 builds on that by improving the architecture documentation with visual diagrams.

This makes the project easier to review because readers can now inspect the system structure, image workflow, video workflow, command flow, persistence flow, and future deployment direction visually before reading the deeper text explanation.
