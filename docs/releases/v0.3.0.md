# VisionCommand AI v0.3.0

## Release Theme

LLM Command Intelligence, LLMOps Monitoring, Command Analytics, JSON Export, and Workspace Recovery.

This release expands VisionCommand AI from a computer vision and video-processing studio into a broader AI command, observability, analytics, and workspace recovery platform.

Since v0.2.0, the project added a full LLM command parser workflow, real LLM provider paths, local Ollama support, LLMOps monitoring, parser and command analytics, exportable observability data, and a safer workspace recovery system.

## Known Limitations

- Local workspace backup is browser-specific because it uses localStorage.
- Undo Clear Workspace is in-memory only and disappears after browser refresh.
- Browser confirmation dialogs are still native `window.confirm` prompts.
- Snapshot JSON can become large when many video or tracking results are included.
- Small local LLM models through Ollama may produce incomplete or noisy JSON.
- Real LLM behavior depends on provider availability and configuration.
- Older command logs may contain legacy parser metadata values.
