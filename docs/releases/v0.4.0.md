Cloud Deployment, Render Live Demo, Production Smoke Testing, Deployment Evidence, and README Live Demo Documentation.

## Major Changes

### 1. First Public Render Deployment

This release includes the first successful cloud deployment of VisionCommand AI.

Deployed Render resources:

- `vision-command-db`
- `vision-command-backend`
- `vision-command-frontend`

The deployment uses:

- Render PostgreSQL for database persistence
- Render Web Service for the FastAPI backend
- Render Static Site for the React/Vite frontend
- Render static site rewrite rules for frontend API routing

The first deployment was done manually through the Render dashboard to support learning, step-by-step debugging, and direct understanding of cloud deployment concepts.

---

### 2. Backend Cloud Deployment

The FastAPI backend was deployed as a Docker-based Render Web Service.

Confirmed backend capabilities:

- Backend service starts successfully
- `/health` returns healthy status
- `/model/info` returns model metadata
- Backend runs with Render-provided runtime port
- Backend reads environment variables from Render
- Backend connects to Render PostgreSQL through `DATABASE_URL`

The backend deployment confirms that the FastAPI service can run outside local Docker Compose and serve public API requests.

---

### 3. Frontend Cloud Deployment

The React/Vite frontend was deployed as a Render Static Site.

Confirmed frontend capabilities:

- Frontend builds successfully with `npm ci && npm run build`
- Static site serves the generated `dist` output
- Public frontend URL loads in the browser
- Fresh incognito browser test passes
- Frontend UI loads without critical console errors
- Frontend can call backend API endpoints through `/api/*`

The frontend deployment confirms that the browser application can run as a public static web app.

---

### 4. Render Static Site API Rewrite

The first frontend API test initially failed because the frontend tried to call `/api/model/info` on the frontend static site.

This was fixed by adding Render rewrite rules:

- `/api/*` rewrites to `https://vision-command-backend.onrender.com/*`
- `/*` rewrites to `/index.html`

This allows frontend requests such as:

- `/api/model/info`
- `/api/db/stats`
- `/api/model/classes`

to reach the deployed FastAPI backend correctly.

## Known Limitations

This is a successful first cloud deployment, but it is still a demo deployment.

Known limitations:

- Render free backend can spin down after inactivity
- First request after inactivity can be slow
- YOLO inference is slow on the free instance
- Detection can take around 1 to 2 minutes on free-tier compute
- Uploaded and generated media are stored on temporary container storage
- Media files may disappear after backend restart or redeploy
- Free PostgreSQL database is temporary unless upgraded
- OpenAI provider is disabled for the first deployment
- Ollama is not used in the hosted deployment
- Video workflows may be slow or unstable on free-tier compute
- Persistent object storage is not yet implemented
- Background job processing is not yet implemented
