# VisionCommand AI v0.6.0 Release Notes

## Release type

Production-readiness portfolio milestone.

## Release summary

VisionCommand AI v0.6.0 packages the project as a validated local Docker demo and professional portfolio release.

This release summarizes the major work completed since v0.5.0, including professional video analysis, command-driven workflow upgrades, analysis-memory retrieval, production-readiness documentation, final smoke validation, and a generated output persistence bugfix.

The release is intentionally labeled v0.6.0, not v1.0.0. The G.9 readiness decision defers v1.0.0 until a later review.

## Previous release baseline

The previous release was v0.5.0, focused on AI workflow intelligence, generated output lineage, analytics, and reporting.

v0.6.0 builds on that foundation by making the project easier to demo, explain, validate, and present as applied AI engineering work.

### Important bugfix

PR #546 fixed generated output PostgreSQL persistence.

The G.7 final smoke run originally found that generated output saves failed because the SQL insert had 30 placeholders while only 15 parameters were passed.

The fix restored the correct generated output insert and conflict-update behavior, added a regression test, and was validated through Docker using the frontend proxy.

## What this release does not claim

This release does not claim:

- active production cloud hosting
- v1.0.0 production readiness
- live camera or real-time stream processing
- identity recognition
- emotion recognition
- guaranteed capture-location inference
- full persistent multi-object tracking in every scenario
- persistent production media storage
- enterprise-grade security or monitoring
- paid cloud infrastructure readiness

## Recommended demo path

Use Local Docker Compose as the recommended demo path.

Recommended explanation:

VisionCommand AI is a full-stack AI assistant for image and video analysis workflows. It combines computer vision, command-driven interaction, generated output history, and retrieval-grounded analysis memory in a local Docker demo environment.
