# VisionCommand AI Documentation Assets

This folder is reserved for lightweight documentation assets used by the project walkthrough and architecture documentation.

The folder structure is intentionally committed before adding final media files so future screenshots, sample references, and rendered diagrams can be organized consistently.

## Folder Structure

```text
docs/assets/
├── screenshots/
├── sample-inputs/
├── sample-outputs/
└── diagrams/
```

## Intended Use

```text
screenshots/
Product walkthrough screenshots and UI evidence.

sample-inputs/
Small sample media references for documentation and demo workflows.

sample-outputs/
Small generated-output references for documentation and demo workflows.

diagrams/
Rendered architecture diagrams or supporting visual documentation.
```

## Asset Guidelines

- Keep committed assets small.
- Do not commit large videos.
- Do not commit private, sensitive, or copyrighted media.
- Prefer compressed images when screenshots are added.
- Use clear filenames that describe the workflow or UI state.
- Keep the Markdown documentation useful even when visual assets are not present.
