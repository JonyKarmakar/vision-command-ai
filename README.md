# VisionCommand AI

VisionCommand AI is an end-to-end AI project for computer vision, media editing, and natural language commands.

The goal of this project is to learn:

- Computer vision
- LLM-based command parsing
- Backend development
- Git and version control
- Docker
- CI/CD
- MLOps
- Data engineering

## First Milestone

Build a simple FastAPI backend with a health check endpoint.
